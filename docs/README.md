# Docs - DevCodes (SpecFirst)

## Por que este arquivo existe

Este índice organiza a documentação canônica do projeto **DevCodes**, estruturada sob a metodologia **SpecFirst**. Os documentos abaixo servem como contrato de alinhamento entre humanos e agentes de IA antes de qualquer implementação.

---

## Rotas Principais

- `README.md` -> Guia geral e setup rápido do DevCodes.
- `AGENTS.md` -> Contrato universal mandatório para agentes de IA.
- `docs/*` -> Documentação canônica técnica, de dados e produto.
